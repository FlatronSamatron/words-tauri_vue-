# Words — Приложение для интервального запоминания слов

## Стек технологий

| Слой      | Технология         |
|-----------|--------------------|
| Frontend  | Vue 3 + TypeScript |
| Backend   | Tauri (Rust)       |
| Хранилище | Локальная БД / JSON (TBD) |

---

## Описание приложения

Десктопное приложение для **интервального запоминания иностранных слов**. Живёт в **системном трее** (пункт управления macOS) и периодически напоминает пользователю пройти мини-игру по повторению слов.

---

## Архитектура и функционал

### 1. Главное окно (Settings / Words)

Открывается через контекстное меню иконки в трее → пункт **"Settings"**.

Содержит **2 вкладки**:

#### 1.1 Вкладка «Settings»
- Настройка **интервала напоминания** (в минутах).
- **Свап направления перевода**: родной → иностранный или наоборот.

#### 1.2 Вкладка «Words»
Разделена на 2 половины:

| Левая часть (форма)             | Правая часть (таблица)                                    |
|---------------------------------|-----------------------------------------------------------|
| Поле **Word**                   | Столбец **Слово**                                         |
| Поле **Translate**              | Столбец **Перевод**                                       |
| Кнопка **Сохранить**            | Столбец **Кол-во ответов**                                |
|                                 | Столбец **Статистика** (% правильных)                     |
|                                 | Кнопки **Удалить** / **Редактировать** (per row)          |

---

### 2. Системный трей (System Tray)

#### Иконка
- Находится в пункте управления macOS.
- **Каждые 5 минут меняет цвет** (индикация: пора пройти игру).
- Цвет возвращается к обычному **только после ответа хотя бы на одно слово**.

#### Правый клик → контекстное меню
| Пункт      | Действие                          |
|------------|-----------------------------------|
| **Settings** | Открывает главное окно настроек |
| **Quit**     | Закрывает приложение            |

#### Левый клик → кастомный попап (Игра)
- Показывает **случайное слово** (или перевод, в зависимости от настройки свапа).
- Две кнопки: **Знаю** / **Не знаю**.
- После нажатия кнопки:
  - Записывается статистика (правильный / неправильный ответ).
  - Показывается следующее рандомное слово.
  - Цикл повторяется, пока пользователь не закроет попап.

## Модель данных

```ts
interface Word {
  id: string
  word: string
  translate: string
  totalAnswers: number   // всего ответов
  correctAnswers: number // правильных ответов
  createdAt: string
}

interface Settings {
  reminderIntervalMinutes: number // интервал напоминания
  swapDirection: boolean          // true = показывать перевод, угадывать слово
}
```
